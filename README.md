Repository adalah ruang penyimpanan atau tempat menyimpan suatu proyek seperti kode, file, dan lainnya.

Repository digunakan untuk menyimpan file proyek di suatu tempat, melihat dan mencatat perubahan yang dikenakan pada suatu proyek itu, dan memudahkan kerjasama tim dalam suatu proyek.

Workshop pada day 1 TIKMENGAJAR bertemakan prompt engineering dan github. 
Pada materi Prompt Engineering dijelaskan bagaimana cara menulis prompt yang benar dan detail ke AI agar hasilnya lebih sesuai dengan keinginan.
Yang perlu diperhatikan saat menulis:
- Role (website atau aplikasi atau yang lainnya)
- Task (tujuan dibuatnya website tersebut)
- Context (detail syarat, keterangan website, desain website, hal yang tidak boleh ada di website)
- Format (apa dan bagaimana hasil dari prompt tersebut)

Git dan GitHub.
Git adalah alat untuk mencatat perubahan file. Github adalah tempat menyimpan proyek git secara online agar bisa dikerjakan bersama. Terdapat git workflow yang berupa working directory/tree, staging area, dan git directory (repository)

Pada workshop ini saya juga belajar cara menggunakan github serta beberapa command dasar seperti
- git innit (untuk repository baru)
- git add (untuk perubahan)
dan lainnya.

Workshop ini menekankan cara menggunakan github untuk menyimpan proyek-proyek yang akan dikerjakan kedepannya, yang mana hal tersebut merupakan hal yang baru bagi saya. Saya rasa workshop ini merupakan bekal yang penting untuk kehidupan mahasiswa teknik informatika dan komputer kedepannya. Walau saya hanya bisa belajar hal dasar dan mempraktikkan sedikit, namun saya rasa dengan workshop ini saya jadi punya kesempatan untuk mempelajari apa itu repository serta bagaimana membangun akun github.
